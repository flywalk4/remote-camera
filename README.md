# 🌕 Remote Camera

iOS-приложение, которое превращает iPhone на штативе в камеру с **полным ручным
управлением с MacBook**. Сделано в первую очередь для съёмки Луны: ISO, выдержка,
ручной фокус с лупой, баланс белого, телевик, RAW и серии кадров для стекинга.

```
 iPhone на штативе (приложение)                  MacBook (любой браузер)
┌─────────────────────────────────┐   Wi-Fi /   ┌──────────────────────────┐
│ AVFoundation: ручная камера     │  режим      │ http://<IP iPhone>:8080  │
│ встроенный HTTP-сервер :8080 ───┼──модема────▶│ превью + гистограмма     │
│ снимки в Documents/Photos       │             │ все настройки, спуск     │
└─────────────────────────────────┘             └──────────────────────────┘
```

На Mac ничего устанавливать не нужно: пульт открывается в браузере, его раздаёт
само приложение на iPhone.

> Почему нативное приложение, а не сайт: Safari не даёт веб-страницам управлять
> ISO, выдержкой и фокусом — только нативный код через AVFoundation.

## Что умеет

**Камера**
- Выбор объектива: ультраширокий / основной / **телевик** (для Луны — самый длинный) + цифровой зум.
- **Экспозиция**: авто (с коррекцией EV и точкой замера по клику) или ручная — ISO и выдержка
  слайдерами и быстрыми кнопками; стрелка экспонометра.
- **Фокус**: авто (клик по превью — точка фокуса) или ручной — положение линзы с шагом 0,001,
  кнопки ±, клавиши `[` `]`; **лупа 2×/4×/8×** показывает центр кадра без уменьшения для точной
  фокусировки.
- **Баланс белого**: авто или ручной (температура и оттенок).
- Ручные настройки сохраняются при смене объектива.

**Съёмка**
- Форматы: HEIF, JPEG, **RAW (DNG)**, **Apple ProRAW** (на Pro-моделях).
- Задержка перед снимком (2/5/10 с) — чтобы штатив перестал дрожать после нажатия.
- **Серии**: N кадров с интервалом — для стекинга (сложения кадров) в AutoStakkert!, Siril, RegiStax и т. п.
- Максимальное разрешение сенсора (до 48 Мп на новых моделях) для HEIF/JPEG/ProRAW.
- Снимки хранятся на iPhone (видны в «Файлы» → На iPhone → Remote Camera),
  скачиваются на Mac из пульта, по желанию дублируются в «Фото».

**Пульт на Mac**
- Живое превью, гистограмма с индикатором пересвета, сетка.
- Красный ночной режим — не сбивает темновую адаптацию глаз.
- Состояние iPhone: батарея, перегрев.
- Пресет «🌕 Луна» одной кнопкой.

**Приложение на iPhone** показывает адрес пульта, превью и кнопку спуска; кнопка
«Затемнить» гасит экран (яркость на минимум), приложение при этом продолжает работать.

## Установка на iPhone

Нужны Mac с **Xcode 15+** и iPhone на **iOS 17+**. Платный аккаунт разработчика не нужен —
подойдёт обычный Apple ID (приложение тогда работает 7 дней, потом просто переустановите из Xcode).

```bash
brew install xcodegen      # генератор Xcode-проекта
xcodegen                   # в папке репозитория создаст RemoteCamera.xcodeproj
open RemoteCamera.xcodeproj
```

В Xcode:
1. Выберите проект **RemoteCamera** → вкладка **Signing & Capabilities** → **Team**: ваш Apple ID
   (Xcode → Settings → Accounts, если ещё не добавлен). Если Xcode пишет, что Bundle Identifier
   занят, замените `com.example.remotecamera` на любой свой, например `com.вашеимя.remotecamera`.
2. Подключите iPhone кабелем, выберите его вверху как устройство запуска и нажмите ▶︎ (⌘R).
3. На iPhone при первом запуске: **Настройки → Основные → VPN и управление устройством** →
   доверьтесь своему сертификату разработчика. Также включите **Режим разработчика**
   (Настройки → Конфиденциальность и безопасность), если iOS попросит.
4. Разрешите приложению доступ к камере и к **локальной сети** (без этого Mac не подключится).

<details>
<summary>Без XcodeGen (создать проект вручную)</summary>

1. Xcode → File → New → Project → iOS **App**, Interface: SwiftUI, Language: Swift, имя `RemoteCamera`.
2. Удалите созданные `ContentView.swift` и `RemoteCameraApp.swift`, перетащите в проект все файлы из
   папки `RemoteCamera/`.
3. Перетащите папку `Web` и выберите **Create folder references** (синяя папка), отметьте таргет.
4. В Build Settings поставьте **iOS Deployment Target 17.0**, **Swift Language Version 5**.
5. Во вкладке **Info** добавьте ключи из раздела `info.properties` файла `project.yml`
   (как минимум `NSCameraUsageDescription`, `NSLocalNetworkUsageDescription`, `NSBonjourServices`,
   `NSPhotoLibraryAddUsageDescription`, `UIFileSharingEnabled`).
</details>

## Использование

1. Поставьте iPhone на штатив и запустите приложение. Сверху будет адрес, например
   `http://192.168.1.23:8080`.
2. Откройте этот адрес в браузере на Mac (Safari или Chrome).
3. iPhone и Mac должны быть в одной сети. **На природе без Wi-Fi**: включите на iPhone
   «Режим модема» и подключите к нему Mac по Wi-Fi или кабелем — адрес будет `http://172.20.10.1:8080`.
4. Не сворачивайте приложение: iOS отключает камеру у приложений в фоне. Экран можно
   затемнить кнопкой «Затемнить».

### Горячие клавиши пульта

| Клавиша | Действие |
|---|---|
| `Пробел` | Снять (с учётом задержки/серии) |
| `Esc` | Остановить серию |
| `L` | Лупа 1× → 2× → 4× → 8× |
| `[` / `]` | Фокус чуть ближе / дальше (с `Shift` — крупнее шаг) |
| `G` | Сетка |
| `H` | Показать/скрыть гистограмму |
| `N` | Красный ночной режим |

## Как снять Луну

1. Нажмите **🌕 Пресет «Луна»**: включится телевик, ручная экспозиция ISO 50 и 1/250 с,
   баланс белого ~4800 K, формат RAW.
2. Наведите iPhone так, чтобы Луна была в центре (удобно включить сетку `G`).
3. **Фокус**: включите лупу 4–8× (`L`), переключите фокус в «Ручной» и двигайте слайдер или
   `[` `]`, пока кратеры на терминаторе (граница света и тени) не станут максимально резкими.
   Бесконечность у iPhone обычно не ровно 1.0 — ищите по картинке.
4. **Экспозиция**: следите за гистограммой — надпись «пересвет» должна исчезнуть. Луна
   освещена Солнцем, поэтому выдержки короткие: обычно ISO 50–100 и 1/250–1/1000 с.
   Лучше чуть недоэкспонировать — RAW вытянет тени, а пересвеченные моря не восстановить.
5. Поставьте задержку 2 с (чтобы штатив успокоился) и серию, например 50 кадров с интервалом 0,5 с.
6. Скачайте DNG на Mac и сложите кадры в AutoStakkert!/Siril/RegiStax — шум уменьшится,
   детализация вырастет.

Длинная экспозиция на iPhone ограничена примерно 1 секундой — для Луны этого более чем
достаточно, но для звёзд и Млечного Пути такой подход не подойдёт.

## Структура

```
project.yml                        описание Xcode-проекта для XcodeGen
RemoteCamera/
  RemoteCameraApp.swift            точка входа, запуск камеры и сервера
  ContentView.swift                экран iPhone: адрес пульта, превью, затемнение
  CameraController.swift           AVFoundation: объективы, ручные настройки, съёмка, серии, превью
  HTTPServer.swift                 мини HTTP-сервер (Network.framework) и MJPEG-поток
  WebAPI.swift                     маршруты API для пульта
  PhotoStore.swift                 хранение снимков
  Models.swift                     модели состояния/настроек (JSON)
  NetworkInfo.swift                IP-адреса iPhone
Web/                               веб-пульт (раздаётся приложением)
  index.html, app.js, style.css
```

### HTTP API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/state` | Все текущие параметры и диапазоны камеры |
| POST | `/api/settings` | `{lens, zoom, exposureMode, iso, shutter, bias, focusMode, lensPosition, wbMode, temperature, tint, point:{x,y}, loupe}` — любое подмножество |
| POST | `/api/capture` | `{format: heif\|jpeg\|raw\|proraw, count, interval, delay, saveToPhotos}` |
| POST | `/api/cancel` | Прервать серию |
| GET | `/api/photos` | Список снимков |
| GET | `/photos/<имя>` | Файл (`?download=1` — скачать) |
| POST | `/api/photos/delete` | `{name}` |
| GET | `/stream` | MJPEG-превью |

Так что камерой можно управлять и скриптом, например:
`curl -X POST http://172.20.10.1:8080/api/capture -d '{"format":"raw","count":100,"interval":1}'`.
