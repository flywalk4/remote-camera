# 📷 Remote Camera

Управление камерой iPhone с MacBook: живое видео на экране Mac, съёмка фото и видео,
смена камеры, зум, фонарик. Не нужно ни Xcode, ни установки приложения на iPhone —
всё работает в браузере через WebRTC.

```
 iPhone (Safari)                         MacBook
┌──────────────────┐   WebRTC видео   ┌─────────────────────┐
│ /phone           │ ───────────────▶ │ пульт (браузер)     │
│ камера + запись  │ ◀─── команды ─── │ кнопки, превью      │
│                  │ ── фото/видео ─▶ │ сохраняет в Загрузки│
└──────────────────┘   DataChannel    └─────────────────────┘
          ▲                                     ▲
          └──── сигналинг (WebSocket) ── node server.js (на Mac)
```

## Быстрый старт

Нужен Node.js 18+ (`brew install node`).

```bash
npm install
npm start
```

1. На Mac откройте **https://localhost:8443/** — это пульт.
2. На iPhone отсканируйте QR-код из терминала (или откройте адрес `https://<IP-Mac>:8443/phone`).
   iPhone и Mac должны быть в **одной Wi-Fi сети**.
3. Сертификат самоподписанный, поэтому Safari покажет предупреждение:
   **«Подробнее» → «Перейти на веб-сайт»** (то же самое один раз на Mac).
   HTTPS обязателен — без него iOS не даёт доступ к камере.
4. На iPhone нажмите **«Включить камеру»** и разрешите доступ. Видео появится на Mac.

## Возможности

| Действие | Кнопка | Клавиша |
|---|---|---|
| Фото (в полном разрешении с камеры) | белый затвор | `Пробел` |
| Запуск/остановка записи видео | красная кнопка | `R` |
| Основная ↔ фронтальная камера | «Сменить камеру» | `C` |
| Сетка «правило третей» | чекбокс | `G` |
| Полный экран | кнопка | `F` |

А также: таймер фото (3/10 с), зум, фонарик (если поддерживает устройство/iOS),
качество 720p / 1080p / 4K, зеркальное отображение, галерея снятого.

**Фото и видео снимаются на самом iPhone** (видео пишется `MediaRecorder` со звуком,
~16 Мбит/с), а затем передаются на Mac и сохраняются в «Загрузки». Поэтому их
качество не зависит от сжатия живого превью. Если связь прервётся во время передачи,
файл отправится заново при переподключении.

## Советы

- Держите страницу на iPhone открытой и на переднем плане: Safari останавливает
  камеру, когда вкладка уходит в фон или экран блокируется. Страница просит
  Wake Lock, но надёжнее выключить автоблокировку на время съёмки.
- Зум и фонарик доступны в Safari на iOS 17+; на старых версиях эти элементы
  просто скрываются.
- Порт можно поменять: `PORT=9000 npm start`.
- Если сменился IP Mac, сертификат перевыпустится автоматически (он хранится в `.cert/`).

## Нужна веб-камера для Zoom/FaceTime?

Этот проект — пульт для съёмки. Если нужно, чтобы iPhone виделся в системе как
обычная веб-камера, в macOS 13+ для этого есть встроенная функция
**Continuity Camera** (iPhone в меню выбора камеры любого приложения).

## Структура

```
server.js          HTTPS-сервер, сертификат, WebSocket-сигналинг
public/phone.*     страница iPhone: захват камеры, выполнение команд, запись, отправка файлов
public/viewer.*    пульт на Mac: превью, кнопки, приём файлов
public/common.js   сигналинг с переподключением, общие константы
public/style.css   стили
```
